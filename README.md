
# Mi Bingo — app web para iPhone

Esta versión funciona desde Safari y se puede añadir a la pantalla de inicio como si fuera una app.

## Funciones

- Cartón de 3 filas × 9 columnas.
- Introducción manual de números.
- Tachado tocando las casillas.
- Tachado por voz.
- Foto del cartón y reconocimiento aproximado de números.
- Teclado rápido del 1 al 90.
- Estadísticas de la partida.
- Aviso de línea y bingo.
- Guardado automático.
- Varios cartones guardados.
- Modo oscuro.
- Funcionamiento offline después de la primera carga, salvo que el reconocimiento de imagen necesite descargar recursos.

## Cómo publicarla gratis

La forma más sencilla es usar Netlify Drop desde Safari o desde cualquier ordenador:

1. Descomprime el ZIP.
2. Sube la carpeta completa a un servicio de alojamiento estático, como Netlify, GitHub Pages o Cloudflare Pages.
3. Abre la dirección resultante en Safari.
4. Pulsa Compartir → Añadir a pantalla de inicio.

## Importante sobre iPhone

- El reconocimiento de voz depende de la compatibilidad de Safari y de los permisos del micrófono.
- El escaneo por cámara usa OCR y puede equivocarse. Revisa siempre los números detectados.
- La web debe servirse por HTTPS para que funcionen correctamente la cámara, el micrófono y la instalación como app.
